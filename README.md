# TCD Origin - 拓扑古文字同源性分析引擎

跨文明古文字符号拓扑不变量分析系统，基于三层拓扑不变量层级互补体系，对甲骨文、楔形文字、埃及圣书体进行结构同源性比较。

## 在线演示

👉 [https://huangao2026.github.io/tcd-origin](https://huangao2026.github.io/tcd-origin)

## 功能

- 🔤 100个古文字字符拓扑特征数据库（甲骨文34 + 楔形文字33 + 圣书体33）
- 🔗 跨文明同源性概率分析
- 📊 拓扑不变量可视化（环数、对称阶、Betti数、欧拉特征数）
- 🌐 文明间距离矩阵热力图
- 🧮 实时拓扑相似度计算器

## 技术架构

- 纯前端单文件应用，零依赖部署
- 拓扑不变量：环数(loop_count)、对称阶(symmetry_order)、Betti数(B₀, B₁)、欧拉特征数(χ)
- 三层权重体系：全局锚点40% + 核心不变量35% + 局部指纹25%
